Interface visual do CapyChain

Explore blocos, faça requisições à API e demonstre o funcionamento da sua blockchain de forma didática.

Tema escuro Paleta laranja capivara API em localhost
GET / POST / DELETE em um só painel
⛓️ Visão geral da cadeia
Carregue a blockchain, veja o tamanho e valide a consistência.
/chain GET • /chain/length • /chain/validate
Cada bloco retornado por GET /chain aparecerá como uma “caixinha” abaixo, com altura, hash, nonce e dados.
🔍 Buscar / Excluir bloco
Utilize altura e hash para localizar ou remover um bloco específico.
POST /chain • DELETE /chain/block
Ambas as ações utilizam height + hash como identificador.
⛏️ Minerar novo bloco
Envie os dados e deixe o node construir um novo bloco.
POST /chain/mine
Resposta será um CapyBlock completo, exibido no console e em caixinha.
🧱 Criar bloco manualmente
Monte um CapyBlock “na mão” para testes e envie à cadeia.
POST /chain/block
Certifique-se de respeitar as regras internas da sua implementação antes de adicionar.
🧩 Node atual
Veja informações do node, voto, dificuldade e peers.
GET /node
Retorna um CapyNode com peers, voto e dificuldade.
👥 Peers, voto e dificuldade
Gerencie peers, vote em um peer e altere a dificuldade de mineração.
/node/peers • /node/vote • /node/difficulty
Clique em um peer nas caixinhas abaixo para preencher automaticamente os campos de voto/remoção.
Envia { "difficulty": <integer> } para POST /node/difficulty.
Cole aqui um array de CapyNode em JSON para sincronizar.
